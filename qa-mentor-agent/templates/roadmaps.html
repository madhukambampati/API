Entry-Level QA Foundations

Start here if you're brand new to software testing

1. What is Software Testing?

1 week ▾
  • Why testing matters, cost of defects
  • QA vs QC vs Testing
  • Core testing principles

2. SDLC & STLC

1 week ▾
  • Waterfall, Agile, Scrum models
  • Software test lifecycle phases
  • Where testing fits in each model

3. Test Case Design

2 weeks ▾
  • Equivalence partitioning
  • Boundary value analysis
  • Decision tables & use case testing

4. Types of Testing

2 weeks ▾
  • Functional: smoke, sanity, regression, integration, UAT
  • Non-functional: performance, security, usability

5. Bug Reporting & Tracking

1 week ▾
  • Writing clear, reproducible bug reports
  • Severity vs. priority
  • Tools: Jira, Azure DevOps

6. Basic SQL for Testers

1-2 weeks ▾
  • SELECT, WHERE, JOIN basics
  • Verifying data changes from the UI in the DB

7. Intro to Automation Concepts

2 weeks ▾
  • Why and when to automate
  • Record & playback vs. scripted automation
  • First look at Selenium

8. First QA Job Prep

Ongoing ▾
  • Resume & portfolio basics
  • Common entry-level interview questions

Manual Tester → SDET

A 6-month plan to move into automation

1. Solidify Manual Testing Fundamentals

2-3 weeks ▾
  • SDLC/STLC, test case design techniques
  • Bug lifecycle, exploratory testing

2. Learn a Programming Language

4-6 weeks ▾
  • Java or Python fundamentals
  • OOP concepts, collections, exception handling

3. Version Control & Dev Tools

1-2 weeks ▾
  • Git basics: branching, commits, PRs
  • IDE setup (IntelliJ / VS Code)

4. Web Automation Fundamentals

4-6 weeks ▾
  • Selenium WebDriver, locators, waits
  • Page Object Model, TestNG/JUnit or pytest

5. API Testing & Automation

2-3 weeks ▾
  • REST concepts, Postman
  • RestAssured or Python requests, JSON parsing

6. CI/CD & Reporting

2 weeks ▾
  • Jenkins or GitHub Actions basics
  • Allure / Extent reports in a pipeline

7. Build a Portfolio Project

2-3 weeks ▾
  • Automate a real public site end-to-end
  • Publish on GitHub with a clear README

8. Interview Prep & Apply

Ongoing ▾
  • Mock interviews, review testing + coding basics
  • Apply to SDET roles

AI-QA Specialist

For SDETs moving into testing AI/LLM-powered features

1. AI/ML Fundamentals for Testers

2-3 weeks ▾
  • What is ML/an LLM, key terms: prompt, token, embedding, hallucination
  • How models are trained at a high level

2. Testing AI-Powered Features

3 weeks ▾
  • Handling non-determinism in outputs
  • Building golden datasets for regression

3. Prompt & Output Evaluation

2-3 weeks ▾
  • Writing eval rubrics and scoring criteria
  • LLM-as-judge patterns

4. Bias, Safety & Responsible AI Testing

2 weeks ▾
  • Testing for bias, toxicity, and safety
  • Basics of red-teaming and guardrail testing

5. Tooling for AI-QA

2-3 weeks ▾
  • Eval frameworks (e.g. promptfoo, DeepEval)
  • Synthetic test data generation, automating evals in CI

6. Performance & Cost Testing for AI Features

1-2 weeks ▾
  • Latency/cost tradeoffs of model choices
  • Load testing AI endpoints

7. Build an AI-QA Case Study

2-3 weeks ▾
  • Pick an LLM feature and design a full eval suite
  • Document methodology and findings

8. Specialize & Apply

Ongoing ▾
  • Follow AI-QA communities and research
  • Apply for AI-QA / ML-QA roles
